화니의 스도쿠

비공개 테스트 · Android

강아지 화니와 함께하는 클래식 스도쿠. 찍기 없이 추리로만 풀려요!

새 게임을 만들었어요. 출시 전에 먼저 해 보고 의견을 들려주세요!

  1. 구글 계정 알려 주기 — 폰 플레이 스토어에 쓰는 Gmail 주소를 카톡으로. 명단에 넣어야 열려요(한 번이면 돼요).
  2. 플레이 스토어에서 열기 → 테스터 되기 → 설치
  3. 14일 동안 지우지 말기 — 구글 출시 조건이 "테스터 12명 · 14일"이에요. 가끔 켜 주면 더 좋아요.
플레이 스토어에서 열기

안 열리면 → 웹에서 테스터 되기

이번에 봐 줬으면 하는 것

  • 처음 4×4 연습판만 하고 나서 9×9 판을 바로 풀 수 있는지
  • 힌트(어디를 볼지 → 왜 그런지 → 숫자) 설명이 이해되는지
  • 쉬움 · 보통 · 어려움 · 전문가 난이도가 이름에 맞는지
  • 광고가 너무 자주 나오지 않는지

"앱을 찾을 수 없음"이 떠요 — 아직 명단에 안 들어간 거예요. 카톡으로 알려 주세요.

카톡 안에서 안 열려요 — 오른쪽 위 ⋮ → "다른 브라우저로 열기"(크롬).
